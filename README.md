# 도로 선호도 지도 · 따라 하기 안내서

서울 시내 도로 상태(속도·혼잡·노면 젖음·공사)를 지도에 색으로 보여주는 웹사이트입니다.
아래 순서대로 하면 **누구나 접속할 수 있는 인터넷 주소**가 생깁니다. 30분이면 충분해요.

---

## 준비물 3가지

| 준비물 | 어디서? |
|---|---|
| 💻 컴퓨터 (크롬 또는 엣지 브라우저) | |
| 📧 이메일 주소 | |
| 🔑 서울 열린데이터광장 **일반 인증키** | https://data.seoul.go.kr → 로그인 → 오른쪽 위 **인증키 신청** → **일반 인증키 신청** |

> 🔑 인증키는 **집 열쇠**와 같아요. 이 안내서에 나오는 **Vercel 화면 한 곳**에만 넣고, 다른 파일에는 절대 쓰지 마세요.

---

## 1단계. 상자 열기 (압축 풀기)

1. 받은 `road-pref-map.zip` 파일을 **더블클릭**하거나, 마우스 오른쪽 버튼 → **압축 풀기**를 누릅니다.
2. `road-pref-map` 폴더 안에 이것들이 보이면 성공!
   - 📄 `index.html`
   - 📄 `README.md`
   - 📁 `api` (안에 `area.js`, `rain.js`, `_hotspots.json`)

---

## 2단계. GitHub 가입하기 (코드를 넣어 두는 보관함)

1. https://github.com 에 들어갑니다.
2. **Sign up** 버튼을 누르고 이메일, 비밀번호, 아이디를 넣습니다.
3. 메일로 온 숫자를 입력하면 가입 끝!

---

## 3단계. 보관함(저장소) 만들기

1. GitHub 오른쪽 위의 **＋** 버튼 → **New repository** 를 누릅니다.
2. **Repository name** 칸에 `road-map` 이라고 씁니다.
3. **Public** 이 선택되어 있는지 봅니다. (그대로 두면 돼요)
4. 맨 아래 초록 버튼 **Create repository** 를 누릅니다.

---

## 4단계. 파일 넣기

1. 방금 만든 화면 가운데에 있는 파란 글씨 **uploading an existing file** 을 누릅니다.
2. 1단계에서 연 `road-pref-map` 폴더를 열고, **안에 있는 것 3개**(`index.html`, `README.md`, `api` 폴더)를 마우스로 한꺼번에 잡아서 브라우저 화면 위에 **끌어다 놓습니다**.
   - ⚠️ `road-pref-map` 폴더 **자체**가 아니라 **안에 든 것들**을 놓아야 해요.
3. 아래로 내려서 초록 버튼 **Commit changes** 를 누릅니다.
4. ✅ 확인: 저장소 첫 화면에 `api` 폴더와 `index.html` 이 바로 보이면 성공!
   `api` 폴더를 눌렀을 때 `area.js`, `rain.js`, `_hotspots.json` 3개가 보여야 해요.

> 🍎 사파리에서 폴더가 안 올라가면: 크롬이나 엣지로 다시 해 보세요.

---

## 5단계. Vercel 가입하기 (웹사이트를 켜 주는 곳)

1. https://vercel.com 에 들어갑니다.
2. **Sign Up** → **Hobby** (무료) 선택 → 이름 입력
3. **Continue with GitHub** 를 누르고, GitHub에서 **Authorize** 를 누릅니다.

---

## 6단계. 보관함 연결하고 열쇠 넣기 ⭐ 가장 중요

1. Vercel 화면에서 **Add New…** → **Project** 를 누릅니다.
2. 목록에서 `road-map` 옆의 **Import** 를 누릅니다.
   - 목록에 안 보이면 **Adjust GitHub App Permissions** 를 눌러 `road-map` 을 허용해 주세요.
3. 다른 건 건드리지 말고, **Environment Variables** 를 눌러 펼칩니다.
4. 이렇게 넣습니다.

   | Key (이름) | Value (값) |
   |---|---|
   | `SEOUL_API_KEY` | 서울 열린데이터광장에서 받은 인증키 |

   - 이름은 **대문자 그대로**, 글자 하나도 틀리면 안 돼요. 값 앞뒤에 빈칸이 없게 붙여 넣으세요.
5. **Add** → 파란 버튼 **Deploy** 를 누릅니다.
6. 1분쯤 기다리면 🎉 축하 화면이 나옵니다.

---

## 7단계. 잘 됐는지 확인하기

1. 축하 화면에서 **Continue to Dashboard** → 위쪽 **Domains** 에 있는 주소를 누릅니다.
   예: `https://road-map-abc123.vercel.app`
2. 주소 뒤에 `/api/rain` 을 붙여서 열어 봅니다.
   예: `https://road-map-abc123.vercel.app/api/rain`
   - ✅ `"ok":true` 가 보이면 **성공!**
   - ❌ 다른 글자가 보이면 아래 **문제 해결** 표를 보세요.
3. 원래 주소로 돌아가면 지도 오른쪽 위에 초록색 **● 실시간** 표시가 떠요.

---

## 8단계. 친구에게 알려 주기

7단계의 주소(`https://…vercel.app`)를 카톡이나 문자로 보내면 누구나 들어올 수 있어요.

---

## 고치고 싶을 때

1. GitHub의 `road-map` 저장소에서 고칠 파일을 누릅니다.
2. 오른쪽 위 **연필 ✏️** 아이콘을 누르고 고칩니다.
3. **Commit changes** 를 누르면 **1분 뒤 웹사이트에 자동 반영**돼요.

## 문제 해결

| 이런 일이 생기면 | 이렇게 하세요 |
|---|---|
| 지도 위 표시가 **데모 스냅샷**이에요 | 주소 뒤에 `/api/rain` 을 붙여 열고, 나오는 메시지를 아래 칸에서 찾아보세요. |
| `SEOUL_API_KEY 환경변수가 설정되지 않았습니다` | Vercel → 내 프로젝트 → **Settings** → **Environment Variables** 에서 6단계 4번을 다시 넣고 → **Deployments** 탭 → 맨 위 줄 오른쪽 **⋯** → **Redeploy**. 열쇠는 다시 배포해야 적용돼요. |
| `인증키가 유효하지 않습니다` (INFO-100) | 인증키를 다시 복사해 넣으세요. 앞뒤 빈칸이 들어가면 안 돼요. 넣은 뒤 꼭 **Redeploy**. |
| `/api/rain` 이 **404** 예요 | GitHub 저장소 첫 화면에 `api` 폴더가 바로 보여야 해요. `road-pref-map` 폴더 안에 들어가 있으면 4단계를 다시 하세요. |
| 어떤 동네는 길에 색이 없어요 | 서울시 실시간 도시데이터는 주요 121곳 주변 도로만 줍니다. 그 밖의 도로는 아직 데이터가 없어요. |
| 지도가 회색이에요 | 인터넷 연결을 확인하고 새로고침(F5) 하세요. |

## 이 웹사이트가 쓰는 데이터

| 화면 항목 | 데이터 | 갱신 |
|---|---|---|
| 도로 속도·혼잡·모양 | 서울시 실시간 도시데이터 (citydata) | 5분 |
| 날씨 (기온·습도·바람·비) | 서울시 실시간 도시데이터 | 5분 |
| 강우량, 비 그친 뒤 시간 | 서울시 강우량 정보 (ListRainfallService) | 10분 |
| 공사·사고 | 서울시 실시간 도시데이터 | 5분 |
| 노면 젖음·결빙 위험 | 위 데이터로 **추정** (실측 아님) | 5분 |

- 같은 장소는 5분 동안 Vercel이 결과를 저장해 두고 다시 써서, 서울시 API 호출 횟수를 아낍니다.
- 선호도 회귀식은 지금 **연습용 가상 데이터**로 계산합니다. 실제 사용자 평가 데이터가 모이면 `/api/training` 을 만들어 바꾸면 됩니다.

## 파일 설명 (궁금한 사람만)

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 전체 (지도, 체크리스트, 회귀식) |
| `api/area.js` | 장소 1곳의 도로·날씨·공사 정보를 서울시에서 받아 전달 (`/api/area?cd=POI009`) |
| `api/rain.js` | 서울 강우량 요약 전달 (`/api/rain`) |
| `api/_hotspots.json` | 서울 주요 121곳의 이름·위치 (밑줄로 시작해서 주소로는 열리지 않아요) |
